# Changelog

## 0.1.0: first release

- **Web app:** sorts comments from YouTube, Instagram, X and TikTok (paste or upload) into
  supportive, neutral, feedback, harassment and threat. Bullying is blurred, kind comments
  come first, and threats and repeat offenders are flagged.
- **Always-on protection:** hides bullying on YouTube (every 2 min), Instagram (5 min) and
  X (3 min) automatically, with one-click Unhide. Runs in the app, by itself
  (`guardian-always-on`), or in Docker.
- **Browser extension:** blurs hurtful comments on YouTube, Instagram, TikTok and X.
- **Weekly kindness email:** a summary of the good parts of the week, never the hate.
- **MCP server (`guardian-mcp`):** lets Claude and other MCP clients check comments for you.
- **One-command install:** `uvx --from git+https://github.com/swetha-8219/Guardian guardian`.
- **Live playground** on GitHub Pages.
